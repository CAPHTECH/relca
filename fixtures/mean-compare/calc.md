# 平均リードタイムで二案を比べる

案件1件。Fast は2分、Slow は5分で `done` になる。従って全流入の期待経過は Fast=2、Slow=5 分でいずれも exact。6分の必須条件には両方合格し、最小化では Fast が Slow を支配する。

- 閾値だけ3分にすると、5 > 3 で Slow を除外する。Fast は採用候補に残る。
- clock だけ4分にすると、Slow は初到達を観測できない。次に到達しうる時刻は少なくとも5分なので下界5分、値は null。hard で「6分以下」は未確定。目的に下界5分を入れてはならない。
- hard を通常の閾値に戻し `verify metric mean.Lead <= 3min` を加える対照では、Slow は hard を満たしても検証違反で除外される。

共有観測の対照では、同じ Done の分位点と到達割合、および閉鎖費用と流入1件あたりの観測費用を追加する。全到達なので割合は1、分位点は2分と5分。1円/分、開始費0円なので閉鎖費用は Fast=2円、Slow=5円。これらの目的を足したり重み付けしたりしない。
