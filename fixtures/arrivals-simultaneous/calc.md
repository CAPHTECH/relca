# F1 同着 FIFO (ADR 0015・0014)

実装出力でなく独立手計算。時間は分。case ID は列順 1,2。FIFO で case1 が先行。

| D1,D2 | 積の質量 | case1終了 | case2終了 |
|---|---|---|---|
|1,1|1/2 × 1/2 = 1/4|1|2|
|1,3|1/4|1|4|
|3,1|1/4|3|4|
|3,3|1/4|3|6|

和は1。within1 は (1/4+1/4,0)=(1/2,0)。within2 は (1/2,1/4)。
各案件とも <=1/2 と >=1/4 を満たす。確率の min=max。
completed_at=elapsed は case1 1..3、case2 2..6、work は各1..3。
End確率1、result_at null、拒否0、容量超過無し。全性質 satisfied。
時刻0で両受付後に開始。live_tasks1 は案件別なので切断しない。
