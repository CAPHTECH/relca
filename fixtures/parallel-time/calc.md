# parallel-time

## 手計算

単位は分。ADR 0001 と設計 v0.1 §6.1・§6.4・§18 に従う。
capacity 2 なので work-conserving により両 Task は時刻 0 に開始する。
各結果は pass のみ。同時刻の開始イベントをどちらから処理しても、次の占有区間は変わらない。

| 経路(開始イベント順) | a の占有区間 | b の占有区間 | join all 完了 | 作業量 |
|---|---|---|---:|---:|
| a, b | [0, 3) | [0, 5) | 5 | 3 + 5 = 8 |
| b, a | [0, 3) | [0, 5) | 5 | 3 + 5 = 8 |

全枝の終端を待つので経過時間は max(3, 5) = 5 分、作業量は 8 分。
join any が無いので result_at は null。両経路が done に到達し、reachable と全体は satisfied。
生存 Task は最大 2、clock 5 分ちょうどで終わるため切断は無い。
取消要求が無いので cancel 宣言は不要。

ADR 0002 により Cut は undeclared、警告 W-CUT-0 を期待する。
未決: なし。手計算のみで、実装との照合はしていない。
