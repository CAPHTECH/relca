# resource-contention

## 手計算

単位は分。ADR 0001 の資源・開始規則と設計 v0.1 §6.4・§18 に従う。
同一 Actor の容量は 1。生成された 2 Task のうち先に容量を獲得する枝を非決定で全展開する。
各結果は pass のみで、時刻と作業量が異なりうる経路は以下で尽きる。

| 経路 | a の占有区間 | b の占有区間 | join all 完了 | 作業量 |
|---|---|---|---:|---:|
| a を先に開始 | [0, 3) | [3, 8) | 8 | 3 + 5 = 8 |
| b を先に開始 | [5, 8) | [0, 5) | 8 | 3 + 5 = 8 |

待機時間は作業量に含めない。いずれも経過 8 分、作業量 8 分、result_at は null。
占有数は常に 0 または 1 で容量を超えないため safety no_resource_overcommit は satisfied。
done に到達する経路があるので reachable も satisfied、全体は satisfied。
待機中も生存 Task として数えて最大 2、clock 8 分ちょうどで終わり切断は無い。
取消要求が無いので cancel 宣言は不要。

ADR 0002 により Cut は undeclared、警告 W-CUT-0 を期待する。
未決: なし。手計算のみで、実装との照合はしていない。
