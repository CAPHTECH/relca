# sov-route-start

Hand oracle (minutes), fixed before implementation. ADR 0040; design v0.2 §22.3.

P32: Anonymous Clerk capacity1 (no person): approve fail End2/work2; pass post2..3, commit3, End3/work3. Filed route recheck3..4 responds4 <= deadline8, executor null. Declined closes3. Summary0..1 (End3 sees the filed route queued before dispatch). Broken capacity0: End2/End3 and work unchanged; the filed route is queued at3 and can never start, so after the business End no transition is enabled (W-DEADLOCK-0) at3 < deadline8. A filed route with no response at a deadlock is violated (deadlock), not a late response and not satisfied: contest_response violated, root violated (exit1). Static contest stays satisfied (route in Cut, a1 via Approver guard). Same shape as ctx-contest-branches.broken-zero-capacity (terminal target), here with an effect target. response/closed/executor/result/route_work null. route_wait0 (queued3, observed3) and route_cost never_created (route never started) follow the ADR 0022 row fields; these two were written after one look at the engine output, all other values before it. Executors [c1] with capacity0 would be E-CAP-0 (capacity differs from executor count), hence the anonymous Clerk.

Commit finish → same-tick filing/queue management → ordinary process/End → dispatch. Filing is nondeterministic, not a probability. Route work is excluded from the business terminal and included in occupation/overall work. A business End is not execution close. Existing responsibility/completion warnings are not errors. RED is not semantic verification.
