# V01-11: 共通障害

設計 v0.1 §18、設計 v0.2 §22.1。実行前に固定した手計算。
確率は受付1件当たり(無次元)、時間・作業量は分。

Power.failed は案件開始前に一度だけ初期化され、障害1/10・正常9/10。
二つの別 Actor A と B は同じ Power.failed を kernel で読み、両方とも障害時 fail、正常時 pass。
初期化し直さず、別Actor名を独立の根拠にしない。

- 障害枝: P(a=fail,b=fail) = (1/10)(1)(1) = 1/10。
- 正常枝: P(a=pass,b=pass) = (9/10)(1)(1) = 9/10。
- 交差する二枝は確率0。各周辺失敗率も1/10。
- 無条件の独立積 (1/10)(1/10)=1/100 はこのモデルの同時失敗ではない。

Aは0..1分、Bは1..2分。全枝 end.done、elapsed=work=2分、終端確率1。
#1(同時失敗)、#2(A)、#3(B)は各上限0.1で satisfied、全体 satisfied/exit0、切断なし。
単一故障は#1の上限だけ0.01へ変える。1/10 > 1/100 で#1のみ violated/exit1。
確率的違反専用の診断コードは無い。property id と verdict で検出する。
