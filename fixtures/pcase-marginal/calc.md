# ADR 0030 F2 正例

各案件の誤り=(4/5)(1/50)+(1/5)(3/20)=8/500+15/500=23/500。計画の19/500は加算の誤記なので手計算で訂正する。故障=(4/5)(1/50)+(1/5)(1/20)=8/500+5/500=13/500。到着0,10、作業1分、clock30で干渉も切断もない。単件対照も同値。

単一変更: 0.15: ok with bad = true; 0.85: ok with bad = false → 0.05: ok with bad = true; 0.95: ok with bad = false。

期待値は仕様から先に固定した手計算で、実装出力の採取ではない。
時間の単位は分。確率は受付案件当たりであり、拒否を再正規化しない。
RED は未実装の観測であり、意味論の検証完了ではない。
