# 旧構文の3案で照合不一致だけを案内する

相手別宣言もreplaceも無い。Cは3+1=4分、Bは1+1=2分。経過と作業量は4/2分。
RobotからBotへのActor/能力/authority/resource各2行と、Doc読み手/v生産者各1行で10行。
既定retire ClerkはC→Bの計算に無いためE-DIFF-0。3案あるのでその照合不一致にだけ intent from C to B の案内を付ける。
W-DIFF-1/2/3=10/0/10、invalid / exit 3。新しいwire欄は一切出さない。
ControlsはAだけに適用し、C/B両方で範囲外のため適用範囲の差分は0。故障対のpreserveに使う比較条件として両側に固定する。
